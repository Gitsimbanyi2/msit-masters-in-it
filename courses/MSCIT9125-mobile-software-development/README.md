# MSCIT9125 — Software Development for Mobile Devices

## Purpose

Design and build mobile applications with attention to UI, offline data, and device security.

## Topic map

- Android / iOS application lifecycle
- UI/UX for small screens; accessibility
- Local storage, SQLite/Room, sync
- REST consumption, JSON, authentication tokens
- Permissions, sandboxing, certificate pinning (concept)
- Store release, versioning, crash reporting
- Cross-platform options (Flutter / React Native) vs native

## Folder

- `notes.md` — your weekly notes
- `assignments/` — CAT scans, practicals, marked work (PDFs gitignored by default)
- `revision.md` — last-week checklist

## Exam / CAT tips

- A mobile CAT almost always wants lifecycle + data persistence
- Call out insecure storage of tokens on the device
