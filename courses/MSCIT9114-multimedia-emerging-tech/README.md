# MSCIT9114 — Multimedia and Emerging Technology

## Purpose

Understand media formats, compression, streaming, and how emerging tech (AR/VR, 5G, AI media) changes products.

## Topic map

- Text, image, audio, video representations
- Compression (lossy vs lossless) and codecs
- Streaming vs download; QoS and buffering
- Authoring tools and accessibility
- Emerging tech: AR/VR, spatial computing, generative media — opportunities and risks
- Ethics: deepfakes, consent, copyright of generated content
