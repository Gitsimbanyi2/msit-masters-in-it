# MSCIT9113 — Advanced Computer Programming with Java

## Purpose

Write maintainable Java beyond syntax: OOP, collections, concurrency, I/O, and APIs.

## Topic map

- OOP: inheritance, interfaces, composition, SOLID in practice
- Collections, generics, equals/hashCode contracts
- Exceptions, logging, and resource management (try-with-resources)
- Threads, executors, race conditions, synchronisation
- File and network I/O; JDBC
- Unit tests (JUnit) and simple build with Maven/Gradle
- REST APIs and packaging (jar / war)

## Folder

- `notes.md` — your weekly notes
- `assignments/` — CAT scans, practicals, marked work (PDFs gitignored by default)
- `revision.md` — last-week checklist

## Exam / CAT tips

- CAT code must compile in your head: types, braces, exceptions
- Explain thread safety if two users can hit the same object
- Prefer interfaces for services you will mock in tests
