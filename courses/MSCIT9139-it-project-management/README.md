# MSCIT9139 — IT Project Management

## Purpose

Plan, run, and close IT projects: scope, time, cost, risk, quality, and stakeholders.

## Topic map

- PMI / PRINCE2 ideas vs agile (Scrum, Kanban)
- Charter, WBS, schedule, critical path
- Costing, earned value (concept)
- Risk register and issue log
- Quality, change control, configuration management
- Stakeholder map and communication plan
- Procurement and vendor management in public sector
- Closing: lessons learned, handover, benefits realisation

## Exam / CAT tips

- A case study wants a risk AND a mitigation, not a list of knowledge areas
- Separate project risk from operational cyber risk
