# MSCIT9112 — Advanced Database Design and Management

## Purpose

Design, normalise, and operate relational databases, and know when NoSQL or replication is the right tool.

## Topic map

- Conceptual, logical, and physical models (ERD → schema)
- Normalisation to 3NF / BCNF; when to denormalise
- SQL: DDL, DML, joins, views, indexes, transactions
- ACID, isolation levels, locking, deadlocks
- Backup, recovery, point-in-time restore
- Replication, partitioning, and high availability
- Security: roles, least privilege, audit trails, encryption at rest
- NoSQL families and polyglot persistence

## Exam / CAT tips

- Always name the keys and cardinalities on an ERD
- A transaction answer without isolation level is incomplete
- Operational questions want backup RPO/RTO, not only CREATE TABLE
