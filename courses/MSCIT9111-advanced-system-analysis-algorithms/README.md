# MSCIT9111 — Advanced System Analysis and Design of Algorithms

## Purpose

Analyse problems, specify systems, and design algorithms that are correct and efficient enough for production systems.

## Topic map

- System analysis vs system design; requirements, use cases, data flow
- Algorithm design strategies: divide-and-conquer, greedy, dynamic programming, backtracking
- Complexity: Big-O, Big-Theta, space vs time, worst / average case
- Searching and sorting as building blocks
- Graph algorithms: BFS, DFS, shortest path, spanning trees
- Correctness: invariants, loop termination, testing vs proof sketches
- From specification to implementation: linking analysis artefacts to code

## Exam / CAT tips

- State time and space complexity before you code
- Prefer a clear invariant over a clever one-liner in CAT answers
- Draw the data-flow or call tree when the question is a case study
