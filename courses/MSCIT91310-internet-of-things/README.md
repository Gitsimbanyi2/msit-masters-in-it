# MSCIT91310 — Internet of Things

## Purpose

Architect IoT systems: devices, gateways, protocols, data, and the security problems they create.

## Topic map

- IoT stack: device, gateway, network, cloud, application
- Sensors/actuators; constrained devices
- Protocols: MQTT, CoAP, HTTP, BLE (when to use which)
- Edge vs cloud processing
- Identity, firmware update, default passwords
- Privacy of telemetry; network segmentation of IoT VLANs
- Use-cases: smart city, agriculture, industrial control (high level)
