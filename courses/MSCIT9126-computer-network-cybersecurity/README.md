# MSCIT9126 — Computer Network and Cybersecurity

## Purpose

Design networks and defend them: routing, services, threats, and controls used in production SOCs.

## Topic map

- OSI / TCP-IP; switching vs routing; VLANs
- IPv4/IPv6, DHCP, DNS, NAT
- Firewalls, VPN, IDS/IPS, WAF
- AAA, directory services, certificates (TLS)
- Common attacks: phishing, ransomware, web RCE, credential stuffing
- Defence in depth; NIST / ISO 27001 control thinking
- Logging and SIEM (Wazuh as a working example)
- Incident handling: identify, contain, eradicate, recover
