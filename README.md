# MsIT — All Courses Workspace

## Overview

This repository is the working folder for the **Master of Science in Information Technology** programme at the [University of Kigali](https://uok.ac.rw/programs/master-of-science-in-information-technology/).

The degree is two years (six trimesters). Official modules are listed below. Each folder holds study notes, CAT/exam revision, and assignment space.

**Student:** Gitsimbanyi Prosper

## Programme aims (UoK)

* Advanced understanding of IT infrastructure and network management
* Skills in cybersecurity, system administration, and IT support
* Preparation for technical leadership in IT management and cybersecurity

## How to use a course folder

```
README.md          module objectives and topic map
notes.md           your study notes
assignments/       CATs, coursework, practicals
revision.md        exam checklist
```

`MSCIT9128` already has CAT-oriented revision for Advanced Distributed Systems (October 2026). Drop lecturer slides and your own PDFs into the matching `assignments/` folder locally if you do not want large binaries on GitHub.
